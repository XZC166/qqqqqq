# 自动批量核验：已执行的工作流

用户在 2026-11-09/10 授权以自动批量核对替代逐条人工审批；不改变真实原文、合法访问和完整性要求。

1. 来源检查通过且字段指纹未变化的记录优先；正文中保留逐字主题依据、字符位置和正文哈希。不能靠 China 单词、参考文献或医学文章里的偶然提及通过。
2. 摘要优先保留核实的来源摘要；无来源摘要时从同篇正文提取完整句子并加“据正文整理：”。关键词仅使用正文实际出现的词。
3. 证据和支持文件仍校验 SHA-256、所属候选、允许访问状态和去重计数。字段、正文、原始证据、支持元数据、来源适配器或校验代码变化会使解析缓存失效；未变化的来源解析和字段核验复用。
4. 主题决定绑定全部导出字段指纹及其决定文件哈希。来源检查通过不自动等于正式；异常保留 pending，所有旧状态和原文保存在本地备份/审计文件。
5. 视频、播客介绍以及指向视频的平台嵌入保留单独状态；没有文字稿不作为视频全文，不下载视频。
6. SQLite 写入、正式导出与全量 Excel 回读顺序执行；不同来源网络采集可以并发。首轮并发导出发生的工作簿版本竞争及一次慢查询引起的 SQLite 锁均未作为有效交付，随后完整顺序重导出并核验。
7. Excel 只有固定九列；超过单元格限制的原文完整保存 UTF-8 相对路径文件。每批更新统计，不把工作池或 pending 计入正式。

代码：batch_review.py、quality_audit.py。测试覆盖国家词误判、参考文献误判、医学/国内健康社媒误判、部分文字稿、旧日期冲突、缓存失效和未明说 video 的视频链接。所有正文和证据只在本地研究副本保存；Git 只提交代码、合成测试和汇总。
