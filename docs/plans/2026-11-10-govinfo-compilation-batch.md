# GovInfo compilation expansion

Extend the existing approved acquisition workflow with an independent adapter for complete Weekly Compilation of Presidential Documents granules. Reuse official API discoveries only as candidates; search snippets are never text evidence.

Require an original public HTML body, its matching public details page, exact package/granule identity, an explicit weekly issue publication date matching the body publication header, matching original heading, complete printed page sequence and closing HTML. Copy the explicitly attributed institutional creator and publisher. Preserve all source prose and notes; remove only publisher control markers and pagination. Hold transcripts with explicit verification limitations. Daily Compilation event dates alone cannot establish publication dates and remain pending.

Add synthetic regression tests first, then implement, run the suite, test against locally saved captures, and acquire bounded batches under robots and rate limits. Keep all original captures, review decisions and copyrighted content local. Export only independently approved records through the existing nine-column boundary.
